# Commemorative-PCB-board-with-NFC-function-for-the-90th-anniversary-of-the-Long-March-victory
## PCB board with NFC function for the 90th anniversary of the Long March victory.
## 这是一款带NFC功能的纪念长征胜利90周年的PCB板，当将带有NFC功能并开启NFC功能的手机靠近PCB板时，PCB板上的发光二极管将被点亮，显示长征当中的重要节点
